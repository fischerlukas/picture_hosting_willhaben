# picture_hosting_willhaben

Titelbilder für LAGER4-Anzeigen auf willhaben im Format 4:5 (Hochformat).
Grund: Die willhaben-App zeigt Suchergebnisse als 3:4-Kacheln und schneidet Querformate seitlich ab.
Herstellung: Original-Rendering auf das Regal zugeschnitten, 4 % weißer Rand, weiß auf 4:5 aufgefüllt, **nicht skaliert** (Original-Pixel).
Pfad: `hero_4x5/<gleicher Pfad wie im Quell-Repo>`.
